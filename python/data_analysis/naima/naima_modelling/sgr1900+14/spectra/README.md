# Standardised gamma-ray spectra (SGR 1900+14 region)

Generated by [`../spectrum_tools.py`](../spectrum_tools.py), reproducing / extending
the input data of **Hnatyk et al. 2022, MNRAS 516, 4196**.

Regenerate everything with:

```bash
conda activate naima
python spectrum_tools.py
```

Two parallel datasets are produced.

## A. Baseline — real Fermi + propagated TeV (scientific default)

The statistically reliable construction, used as the default in the notebooks.

| File | Content | Points |
|------|---------|--------|
| `fermi_real_4fgl.ecsv`            | **Real** Fermi-LAT SED (from `../FERMI_CATALOG.txt`): 6 detections + 2 upper limits | 8 |
| `hess_hots_propagated.ecsv`       | H.E.S.S. PL sampled sparsely, **bow-tie** (propagated) errors | 4 |
| `hawc_3hwc_propagated.ecsv`       | HAWC PL sampled sparsely, bow-tie errors (comparison only) | 6 |
| `combined_real_baseline.ecsv`     | **Fermi(real) + H.E.S.S.** — the fit dataset | 12 |
| `combined_real_baseline_hawc.ecsv`| + HAWC | 18 |

- **Fermi** points are real (real asymmetric errors, real upper limits) — no invention.
- **TeV** butterflies are sampled sparsely (a few per decade) and each point gets the
  error from propagating the power-law fit covariance,
  `δF/F = sqrt((σ_N0/N0)² + (ln(E/E_piv)·σ_Γ)²)` — narrowest at the pivot, widening out.
- Fit with **inverse-variance weighting** (the maximum-likelihood optimum); the bands
  balance naturally without any equal-weighting trick.
- **Caveat:** sampling a butterfly into points is not perfectly rigorous (the points are
  not independent — they share one 2-parameter fit), so the TeV sampling is deliberately
  sparse and treated as a weak power-law prior.

## B. Cross-check — flat 0.2·F equal weighting (paper reproduction)

The construction of Hnatyk et al. 2022: 20+20 log-spaced points, constant `δF = 0.2·F`
(every point weighs equally). The notebooks refit on this to show the conclusions are
robust to the data construction.

| File | Content | Points |
|------|---------|--------|
| `fermi_4fgl_j1908.ecsv`        | Fermi-LAT, flat 20% | 20 |
| `hess_hots_j1907.ecsv`         | H.E.S.S., flat 20% | 20 |
| `hawc_3hwc_j1907.ecsv`         | HAWC, flat 20% | 20 |
| `combined_fermi_hess.ecsv`     | Fermi + H.E.S.S. (paper's fitted set) | 40 |
| `combined_fermi_hess_hawc.ecsv`| + HAWC | 60 |

## Column format (naima-native)

| Column | Unit | Meaning |
|--------|------|---------|
| `energy`        | GeV | bin centre (geometric mean of edges) |
| `energy_lo`     | GeV | lower bin edge |
| `energy_hi`     | GeV | upper bin edge |
| `flux`          | 1/(cm² s GeV) | differential flux dN/dE (the UL level for UL rows) |
| `flux_error_lo` | 1/(cm² s GeV) | lower 1σ flux error |
| `flux_error_hi` | 1/(cm² s GeV) | upper 1σ flux error |
| `ul`            | bool | upper-limit flag |
| `instrument`    | str | instrument name |
| `group`         | int | instrument id (for naima) |

`table.meta["keywords"]["cl"]["value"]` holds the upper-limit confidence level. These
are exactly the column names `naima.run_sampler` expects.

## Adding another telescope

- **Power-law / butterfly:** add an entry to `PUBLISHED` in `spectrum_tools.py` and call
  `butterfly_spectrum(params, error_model="propagated")` (or `"flat"`).
- **Real flux points:** call `standardise_points(energy, flux, flux_error_lo,
  flux_error_hi, energy_lo, energy_hi, instrument, source, ul=..., cl=...)` with astropy
  `Quantity` arrays — handles asymmetric errors and upper limits.
- **A fermipy SED table:** use `load_fermi_catalog(path)` as a template.
